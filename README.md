 # CLI Task Manager

A simple Command Line Interface (CLI) Task Manager built with JavaScript (Node.js). This project demonstrates the use of ES6 modules, classes, and Git/GitHub workflows.

---

## Features

- Add a new task
- Update an existing task
- Delete a task
- Display all tasks


---

## Technologies Used

- JavaScript (ES6+)
- Node.js
- Git
- GitHub

---

## Project Structure

```
cli-task-manager/
│── app.js
│── Task.js
└── README.md
```

---

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/cli-task-manager.git
```

Navigate into the project folder:

```bash
cd cli-task-manager
```

Install dependencies (if any):

```bash
npm install
```

---

## Run the Project

```bash
node app.js
```
